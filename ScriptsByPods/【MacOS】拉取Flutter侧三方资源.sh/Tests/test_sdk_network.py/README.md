## 🔥 <span id="前言">前言</span>

用 Python 标准库运行真实脚本定义和随包适配器，只替换网络探测及 SDK 执行文件。不下载真实 SDK、不运行 CocoaPods，不修改系统环境。

## 一、运行

`python3 -B <本目录>/test_sdk_network.py`。临时中文空格目录覆盖首次 SDK 失败重试、健康探测取消不进其它候选、pub 准备取消原码、原 pub 业务失败只执行一次，以及健康 module 零探测跳过。配置备份及显式重生成流程沿用原逻辑。

<!-- jobs-language-terminal-style-v1 -->

**终端配色保护：** `test_sdk_network.py` 直接运行时，在可可靠保存与恢复配色的交互终端中临时使用黑底白字和统一强调色；正常退出、失败及可捕获中断后恢复进入前的配色，保留原业务清理和退出状态。导入本文件不接管终端；无法可靠保护、纯文本模式或无交互终端时按纯文本约定降级。运行中另行修改的颜色会保留并报告冲突，强制终止后可按运行提示使用独立恢复入口。 模块启动等无法安全重复初始化的场景不重启原程序。
